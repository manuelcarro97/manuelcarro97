# Manuel Carro Suárez

Desarrollador backend con ~2,5 años de experiencia en **Java/Spring Boot** y **C#/.NET**. Vivo en A Coruña.

He trabajado en aplicaciones de gestión empresarial: APIs REST, bases de datos relacionales, migración de .NET Core 3.1 a .NET 8 y despliegues con pipelines CI/CD.

## Stack

- **Backend:** Java, Spring Boot, JPA/Hibernate, JUnit, C#, .NET 8, ASP.NET Core, Entity Framework
- **Datos:** PostgreSQL, SQL Server
- **DevOps:** Docker, GitHub Actions, Azure DevOps, Linux
- **Web:** JavaScript, Node.js, Cloudflare Workers, Firebase

## Proyectos destacados

**[reservas](https://github.com/manuelcarro97/reservas)** ([demo](https://reservas-6d51b.web.app/r/demo)): app de reservas de mesa para restaurantes. Backend Java 21 + Spring Boot 4 con arquitectura hexagonal, PostgreSQL y control de overbooking concurrente. Frontend Angular 22 con editor de plano interactivo, panel del dueño y página de reserva incrustable en cualquier web. ~1.400 tests (Testcontainers y Vitest), CI con GitHub Actions, desplegada en Render y Firebase Hosting.

**[arquitect-app](https://github.com/manuelcarro97/arquitect-app)** ([demo](https://reformas-app-5f07c.web.app)): editor de planos de viviendas en 2D y 3D con React, TypeScript y Three.js. Dominio separado de la interfaz, 109 tests y CI con GitHub Actions.

**[Kafé](https://github.com/manuelcarro97/kafe-bar-web)** ([demo](https://kafe-143b5.web.app)): web bilingüe en producción para un bar-restaurante real. Incluye panel de administración, API en Cloudflare Workers con verificación manual de JWT y despliegue continuo con GitHub Actions.
